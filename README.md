# Planning Tracker

A planning and tracking application designed to simplify the management of schedules, courses, groups, and timetables.

## About the Project

As a planning coordinator, I identified repetitive tasks that required significant time and effort. I developed this application with the assistance of Claude to simplify the tracking process and improve my workflow.

The project is based on a real professional need and aims to make planning activities easier to manage.

## Objectives

- Simplify planning and schedule tracking.
- Improve the organization of planning information.
- Reduce repetitive manual tasks.
- Explore practical solutions to everyday professional challenges.

## My Role

- Tested the application and requested corrections.
- Reviewed the results and improved the application iteratively.
