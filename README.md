# Planning Tracker

A planning and course tracking application designed to simplify the management of academic schedules, courses, student groups, and teaching hours.

## About the Project

As a Planning Coordinator, I identified repetitive tasks and organizational challenges that required significant time and effort. This project aims to simplify planning activities, improve the monitoring of courses and teaching hours, and make daily workflow more efficient.

The application addresses real professional needs by providing a structured approach to managing academic planning information.

## Objectives

- Simplify planning and course tracking.
- Improve the organization of academic schedules and student groups.
- Monitor planned, completed, and remaining teaching hours.
- Reduce repetitive manual tasks.
- Improve the accuracy and accessibility of planning information.
- Increase productivity and operational efficiency.

## Future Improvements and New Features

- **Advanced Course Tracking:** Monitor planned courses, completed sessions, and remaining teaching hours.
- **Student Group Management:** Improve the organization and tracking of student groups.
- **Timetable Management:** Simplify the creation, organization, and updating of academic schedules.
- **Teaching Workload Monitoring:** Compare planned teaching hours with completed hours and identify discrepancies.
- **Excel Import and Export:** Import planning data from Excel files and export reports for administrative use.
- **Automated Validation:** Detect missing information, inconsistent data, and scheduling conflicts.
- **Dashboard and Statistics:** Display an overview of courses, groups, schedules, and teaching hours.
- **User Interface Improvements:** Enhance navigation, usability, and accessibility.
- **Data Reliability:** Strengthen data validation, error handling, and information consistency.
- **Technical Documentation and Testing:** Document the application architecture and introduce automated tests.
